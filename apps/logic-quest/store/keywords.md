# ASO — search intents and keyword placement

No keyword stuffing, no competitor names, no unverifiable claims ("#1", "best", "IQ boost").
Google Play indexes the title, short description and full description; repeat core intents naturally 2–4 times.

## Positioning (differentiation)

1. **Every answer explained** — explanations are generated from the same rule that produced the puzzle.
2. **Proven-unique solutions** — logic puzzles are machine-checked (marketing may say "every puzzle has exactly one answer").
3. **Daily challenge offline**, identical for everyone on a date.
4. **Private by design** — no account.
