# ASO keyword research — DevSpeak

**Method and limits.** This is a qualitative, search-intent analysis based on the target audience
and on how Play ranks apps (title > short description > full description, plus install/retention
signals). No paid keyword-volume tool was used. Validate with Play Console → *Statistics → Store
listing acquisition by search term* after launch, and iterate monthly.

## Primary intents (target in title / short description)

| Query intent | Placement | Rationale |
| --- | --- | --- |
| english for developers | Title ("English for Devs"), full description first lines | Exact audience match, low competition from generic English apps |
| technical english | Short description, section header | Common learner phrasing |
| english for IT / IT english | Full description | Used in FR/ES/LatAm job markets |
| IT interview english / tech interview | Short description ("interview skills"), section header | High-motivation intent (job seekers) |

## Secondary intents (full description, natural use only)

software engineering vocabulary · tech vocabulary · business english for developers ·

java interview questions english · react interview english · speaking practice

## Localized intents

- **fr-FR:** anglais technique, anglais pour développeurs, anglais informatique, entretien en anglais
- **es-ES / LatAm:** inglés técnico, inglés para programadores, inglés para desarrolladores, entrevista en inglés

## Rules we follow

- No keyword stuffing, no competitor names, no repeated keyword lists (Play metadata policy).
- No claims of rankings, ratings, testimonials or guaranteed hiring outcomes.
- Screenshots are genuine app captures with short captions using the same intents.

## Competitive positioning

Generic apps (vocabulary-only or travel English) do not cover meetings, code reviews, incidents
or tech interviews. DevSpeak's differentiation: developer-specific situations + interview paths +
offline + no account.
