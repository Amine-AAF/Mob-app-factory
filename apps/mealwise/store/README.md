# MealWise — Google Play release package

Nothing in this folder publishes anything. Publication is manual and requires explicit approval
(see `factory/documentation/parallel-development.md` §7).

| File | Purpose |
| --- | --- |
| `listing-en.md`, `listing-fr.md`, `listing-es.md` | Title, short and full description per language |
| `data-safety.md` | Answers for the Play Console "Data safety" form |
| `privacy-policy.md` | Privacy policy text to host at `EXPO_PUBLIC_PRIVACY_URL` |
| `content-rating.md` | IARC questionnaire answers |
| `graphics/` | `play-icon-512.png`, `feature-graphic-1024x500.png` (generated by `pnpm brand-assets apps/mealwise`) |

## Google Play readiness checklist

### Identity & configuration
- [ ] Replace the placeholder package id `com.mealwise.app` with a definitive id on a domain you own (`app.manifest.json`). **Permanent after the first upload.**
- [ ] `version` / `versionCode` bumped in `app.manifest.json` for every upload.
- [ ] `eas init` run in `apps/mealwise`, `EAS_PROJECT_ID` set (CI variable).
- [ ] Upload key / app signing configured in Play Console (Play App Signing).

### Monetization
- [ ] Play Console: create subscriptions `mealwise_premium_monthly` (≈ 2.99 USD), `mealwise_premium_annual` (≈ 17.99 USD) and the in-app product `mealwise_premium_lifetime` (≈ 29.99 USD); set local prices.
- [ ] RevenueCat: project, Android app, entitlement `premium`, offering `default` with monthly / annual / lifetime packages; set `EXPO_PUBLIC_REVENUECAT_ANDROID_KEY` (protected variable).
- [ ] AdMob: app + one **banner** unit; set `ADMOB_ANDROID_APP_ID` and `EXPO_PUBLIC_ADMOB_BANNER_ID` (production only — dev/preview always use Google test IDs).
- [ ] AdMob › Privacy & messaging: publish a GDPR (EEA/UK) consent message and a US state regulations message; test with a debug geography.
- [ ] Test purchase, cancellation, restore and lifetime with license testers on the internal track.

### Policy & store listing
- [ ] Host the privacy policy and terms; set `EXPO_PUBLIC_PRIVACY_URL` / `EXPO_PUBLIC_TERMS_URL`; add the policy URL in Play Console.
- [ ] Data safety form filled from `data-safety.md` (includes the AdMob SDK disclosures).
- [ ] Content rating questionnaire (`content-rating.md`) → expected rating: Everyone / PEGI 3.
- [ ] Target audience: 13+ (not designed for children; ads present). Not in the Families program.
- [ ] Ads declaration: "Contains ads" = yes.
- [ ] Health claims: the listing and the app present nutrition figures as estimates, not medical advice (no "Health" app category; category Food & Drink).
- [ ] Listings EN/FR/ES pasted; 8 phone screenshots per language (Home, Planner, Recipe, Cooking mode, Grocery list, Pantry, Templates, Nutrition), dark mode in at least one.
- [ ] Feature graphic and 512 px icon uploaded from `graphics/`.

### Quality gates
- [ ] `pnpm --filter mealwise typecheck` and `pnpm --filter mealwise test` green.
- [ ] `pnpm registry:check` green for mealwise.
- [ ] `npx expo export --platform android` succeeds.
- [ ] Preview build (`eas build -p android --profile preview`) installed and smoke-tested on Android 8, 13 and 15 (notification permission prompt, timers with screen off, backup export/import through the system picker, share sheet).
- [ ] TalkBack pass on the 5 tabs and cooking mode; font scale 1.6×; dark mode.
- [ ] Offline test: airplane mode from first launch (onboarding → plan → list → cooking).
- [ ] Production build (`--profile production`, `.aab`) uploaded to the **internal** track, then closed testing (12+ testers for 14 days for new personal accounts).
